# Прикладной слой

Прикладной слой — **стол**: он ведёт одну игру. Один запущенный движок —
один стол (см. [0018](../../decisions/0018-one-table-tokens-ports.md)).

## Что держит стол

- состояние игры (или «игры нет», пока никто не сел);
- случайность игры;
- историю событий — полную правду, её отдают после конца игры;
- подключённых клиентов и кто из них какой игрок;
- токены игроков для переподключения.

## Что делает стол

| Вызов | Что происходит |
| --- | --- |
| клиент подключился | `welcome` с номером клиента и снимок |
| команда игрока | вход домена → каждому его сообщение через видимость; отказ — только отправителю |
| `join` | как команда; севшему — ещё и его токен |
| `resume` с токеном | соединение снова этот игрок; «связь восстановлена», таймер отменён, свежий снимок |
| `snapshot` | свежий снимок |
| `history` | история событий, только после конца игры |
| клиент отключился | если это игрок — «потеря связи» и таймер на 60 секунд |
| таймер сработал | «таймаут» |

Команды выполняются строго по одной: методы стола синхронные, а адаптер
зовёт их из одного цикла asyncio.

**Номер клиента** выдаётся каждому соединению. Сев за стол, клиент
становится игроком с тем же номером. Вернувшись по токену, новое
соединение получает номер прежнего игрока.

**Кто что получает.** Игрок — сообщения через видимость. Клиент, который
не сел за стол, видит только лобби: сообщения лобби, начало игры и её
отмену. Во время игры его снимок пуст.

Если игрок подключился заново, пока старое соединение ещё числится живым,
новое забирает игрока себе: старое могло просто зависнуть.

## Порты

Прикладной слой объявляет, что ему нужно снаружи, а адаптеры это
реализуют.

| Порт | Что умеет | Настоящий | В тестах |
| --- | --- | --- | --- |
| Отправитель | доставить клиенту исходящее | очередь на соединение в WebSocket-адаптере | список отправленного |
| Таймер | запустить по ключу через N секунд; отменить | `asyncio` | ручные часы |

Исходящее — `welcome`, `token`, `snapshot`, `message`, `rejected`,
`history` (форма — в [адаптерах](../adapters/README.md)).
