# Адаптеры

## WebSocket (FastAPI)

Один путь `/ws`. На каждое соединение:

- номер клиента;
- своя очередь исходящего и задача, которая её пишет в сокет, — медленный
  клиент не тормозит остальных;
- чтение входящего JSON → вызов стола;
- обрыв сокета → стол «клиент отключился».

Таймер — `loop.call_later` с отменой по ключу.

## JSON

Каждое сообщение в обе стороны — объект с полем `type`:
`{"type": "...", ...поля}`.

### От клиента

| `type` | Поля |
| --- | --- |
| `join`, `leave`, `start` | — |
| `change_settings` | `settings` |
| `prepare` | `hand`, `chips` |
| `shoot` | `chamber`, `target` |
| `use_item` | `item`, необязательные `player`, `target`, `chamber`, `take` |
| `resume` | `token` |
| `snapshot`, `history` | — |

Разбор строгий: неизвестный `type`, лишнее, недостающее или неверного типа
поле — `rejected` с кодом `bad_request`; соединение живёт дальше.

### От движка

| `type` | Поля |
| --- | --- |
| `welcome` | `client` |
| `token` | `token` |
| `snapshot` | `view` — снимок или `null` |
| `message` | `message` — сообщение домена |
| `rejected` | `code` |
| `history` | `events` |

Сообщения, события и снимки кодируются по одному правилу:

- класс → объект, `type` — имя класса в `snake_case`;
- перечисление → его значение в нижнем регистре (`"reverse"`, `"away"`);
- кортеж → массив, словарь → объект с ключами-строками;
- эффект → объект со своим `type` (`{"type": "shield", "turn": 1}`).
