# Правила

Правило — чистая функция: берёт [состояние](state.md) и команду,
возвращает новое состояние и события. Недопустимая команда —
`IllegalAction(code)`, состояние при этом не меняется. Что игрок увидит
из событий, решает модуль видимости, а не правило (см.
[0013](../../decisions/0013-events-and-visibility-function.md)).

## Вход

```python
handle(game, actor: PlayerID | None, command, rng) -> Outcome(game | None, events)
```

- `actor = None` — команда движка: потеря связи, таймаут.
- `game = None` в ответе — игры больше нет: хост ушёл из лобби.
- Пока кто-то `AWAY`, в игре принимаются только команды присутствия, а в
  лобби не принимается только `Start`.
- По стадии `handle` выбирает, какому правилу отдать команду.

## Правила по стадиям

| Стадия | Правило | Кто вызывает |
| --- | --- | --- |
| `Lobby` | `join`, `leave`, `change_settings`, `start` | игрок, хост |
| `Lobby` | `disconnect`, `reconnect`, `timeout` | движок |
| `InProgress` | `prepare` | живой игрок в начале ряда |
| `InProgress` | `shoot`, `apply` | активный игрок |
| `InProgress` | `disconnect`, `reconnect`, `withdraw` | движок |
| `Finished` | — | |

Бездействие игрока движок не обрабатывает: он ждёт. Таймер хода, если
понадобится, — забота транспортного слоя.

### Внутренние правила

Их не вызывает команда — их запускают другие правила.

| Правило | Что делает | Кто запускает |
| --- | --- | --- |
| `start_round` | жизни, перетасованный круг, первый ходящий, `start_spread` | `start`, конец раунда |
| `start_spread` | число камор, выдача → `Preparing` | `start_round`, конец ряда |
| `load` | руки и фишки в места, зарядка → `Shooting` | `prepare`, когда решили все живые; выбывание |
| `settle` | последствия действия | `shoot`, `apply`, `withdraw` |
| `finish` | переход в `Finished` | конец раунда |

## Лобби

Игры нет, пока никто не сел за стол. Первый `Join` создаёт `Lobby` с
настройками по умолчанию.

| Команда | Кто | Можно, если | Результат | События |
| --- | --- | --- | --- | --- |
| `Join` | игрок | ещё не за столом; за столом меньше 6 | сел; первый — хост | `Joined` |
| `Leave` | игрок | за столом | ушёл; ушёл хост — игры нет | `Left` или `Cancelled` |
| `ChangeSettings` | хост | настройки в пределах [параметров](../../../rules/parameters.md) | новые настройки | `SettingsChanged` |
| `Start` | хост | за столом 2–6; никого `AWAY` | `InProgress`, `start_round` | `GameStarted`, затем события `start_round` |
| `Disconnect` | движок | игрок `PRESENT` | `AWAY` | `Disconnected` |
| `Reconnect` | движок | игрок `AWAY` | `PRESENT` | `Reconnected` |
| `Timeout` | движок | игрок `AWAY` | как `Leave` | `Left` или `Cancelled` |

Проверка настроек: пределы «от–до» не перевёрнуты и лежат внутри
параметров; нижний предел патронов меньше нижнего предела камор.
Исключить можно любые предметы, в том числе все.

Команда игрока не из лобби (уже идёт игра) — отказ. Как
переподключившийся клиент доказывает, что он тот же игрок, — забота
адаптера.

## Игра идёт

| Команда | Кто | Можно, если | События |
| --- | --- | --- | --- |
| `Prepare` | живой игрок | начало ряда; он ещё не решил | `Prepared`; когда решили все — события `load` |
| `Shoot` | активный | идёт стрельба | см. [выстрел](#выстрел) |
| `UseItem` | активный | идёт стрельба | см. [применение предмета](#применение-предмета) |
| `Disconnect` | движок | игрок `PRESENT` | `Disconnected` |
| `Reconnect` | движок | игрок `AWAY` | `Reconnected` |
| `Timeout` | движок | игрок `AWAY` | см. [выбывание](#выбывание) |

Пока кто-то `AWAY`, `Prepare`, `Shoot` и `UseItem` — отказ.

## Начало раунда

`start_round` — после `Start` и после каждого раунда, если игра не
кончилась:

1. `start_health` — случайно в пределах настройки.
2. `circle` — невыбывшие игроки, перетасованные.
3. `first` — тот, кто реже всех начинал раунды (по `results`); при
   равенстве — случайный из них. `active = first`, `turn = 1`.
4. Места заново: жизни `start_health`, пустая рука, ноль фишек, без
   эффектов.
5. Событие `RoundStarted`, затем `start_spread`.

## Начало ряда

`start_spread` — в начале раунда и когда кончились каморы:

1. `size` — случайно в пределах настройки.
2. Набор выдачи: сколько предметов и какие классы — по
   [параметрам](../../../rules/parameters.md); класс без предметов в игре
   не выпадает.
3. Каждому живому по предмету каждого класса набора, независимо.
4. `Preparing(size, offers, choices={})`, событие `SpreadStarted`.

Клиент получает число камор и выдачу сразу, а показывает в порядке
правил (см. [0016](../../decisions/0016-spread-start-is-one-step.md)).

`Prepare(hand, chips)` — одно решение игрока:

- рука собрана из прежних и выпавших предметов (с учётом повторов), не
  больше лимита руки;
- `chips` — по числу на каждую камору, неотрицательные, в сумме все
  заработанные фишки игрока;
- повторное решение — отказ.

`load` — когда решение есть у каждого живого. Решение выбывшего, если он
успел его отправить, тоже учитывается.

1. Руки из решений становятся руками мест; фишки мест — `0`.
2. Число патронов — случайно в пределах настройки, но не больше
   `size − 1`.
3. Патроны раскладываются по весам из всех решений (см.
   [шансы зарядки](../../../rules/chapters/spread.md#шансы-зарядки)).
4. `Shooting(chambers, chips, announced, revealed={})`, событие `Loaded`.

## Выстрел

`Shoot(chamber, target)`:

1. **Допустимость.** Камора не использована, цель жива. Если на стрелке
   в силе `PlayAlong`, цель должна совпасть; если `TryThis` — камора.
   «В силе» — `round.turn > effect.turn`: принуждение на себя действует
   со следующего хода.
2. **Камора.** `used = True`; снимаются все `TryThis` на эту камору.
3. **Попадание.** Урон 1, с `FullForce` стрелка — 2, `FullForce`
   снимается. `Shield` цели гасит урон до 0 и снимается.
4. **Холостой в себя** при оставшихся патронах — фишка стрелку.
5. **Ход.** Выстрел заканчивает ход, если у стрелка нет `Double`; `Double`
   снимается.
6. `settle`.

События по порядку: `Shot`, `EffectRemoved` за каждый снятый эффект,
`ChipEarned`, затем события `settle`.

## Применение предмета

`UseItem(item, player?, target?, chamber?, take?)`:

1. **Общие проверки.** Предмет в руке; переданы ровно те поля, что нужны
   по [каталогу](commands.md#каталог-предметов); выбранный игрок жив,
   камора не использована. У «Пора делиться» `player` — не сам
   применивший.
2. Предмет уходит из руки.
3. **Ветка предмета** — по таблице ниже.
4. `settle`.

| Предмет | Что меняет | События | Впустую, если |
| --- | --- | --- | --- |
| Одним глазом | `revealed[actor] += chamber` | `WeightSeen` | — |
| Во все глаза | `revealed[actor]` — все каморы | `WeightsSeen` | — |
| Реверс | `loaded` каморы наоборот | `Reversed` | — |
| Хочу ещё | патрон в пустую неиспользованную по весам | `CartridgeAdded` | пустых неиспользованных нет |
| Мне страшно | патрон снят с заряженной неиспользованной по обратным весам | `CartridgeRemoved` | заряженных неиспользованных нет |
| Что тут у нас | `used = True` как у выстрела, без урона и фишки | `Peeked` | — |
| ХАХхаахХАх | патроны заново по неиспользованным, по весам | `Shaken` | патронов нет |
| Глоток воды | `health + 1`, не выше `start_health` | `Healed` | жизни полные |
| Сомнительное удовольствие | 50%: `+2` (не выше `start_health`), 50%: `−1` | `Gambled` | — |
| Как новый | `health = start_health` | `Healed` | жизни полные |
| Пасс | ход кончается | `Passed` | — |
| Дубль, Со всей дури, Настроечный щит | эффект на применившем | `EffectAdded` | такой эффект уже есть |
| Попробуй вот эту, Подыграй мне | эффект на `player` | `EffectAdded` | такой эффект на нём уже есть |
| Пора делиться, `ITEM` | случайный предмет соперника — в руку | `ItemStolen` | рука соперника пуста; выпала «Пора делиться» |
| Пора делиться, `CHIP` | фишка соперника — себе | `ChipStolen` | фишек у соперника нет |
| Джекпот | `chips + 3` | `Jackpot` | — |

Впустую — событие `Wasted` вместо события предмета.

## Выбывание

`Timeout` в игре:

1. `presence = WITHDRAWN`, событие `Withdrew`.
2. Если он ещё жив: `health = 0`.
3. `settle`: гибель, конец раунда, конец хода, если ходил он.
4. В начале ряда — `load`, если все оставшиеся живые уже решили.

## Конец раунда и игры

Живых осталось ≤ 1:

1. `results += RoundResult(first, winner)`, событие `RoundEnded`.
2. Если сыграны все раунды или невыбывших меньше двух — `finish`:
   `Finished`, событие `GameFinished(winners)`. Победители — невыбывшие
   с наибольшим числом побед.
3. Иначе — `start_round`.

## Эффекты

Эффект — данные без поведения (см.
[0015](../../decisions/0015-effects-are-data.md)). Где эффект влияет на
игру, там его и проверяют: урон и «Дубль» — в выстреле, сроки — в
`expired`.

| Эффект | Где влияет | Когда снимается |
| --- | --- | --- |
| `Double` | выстрел не заканчивает ход | выстрел; конец хода |
| `FullForce` | урон ×2 | попадание стрелка |
| `Shield` | урон 0 | попадание в владельца; конец хода `turn + 1` |
| `PlayAlong` | цель выстрела | конец первого хода владельца после `turn`; гибель цели |
| `TryThis` | камора выстрела | конец первого хода владельца после `turn`; камору использовали |

```python
def expired(e, owner, ended_turn, ended_active) -> bool:
    match e:
        case Double():           return True
        case Shield(turn=t):     return ended_turn >= t + 1
        case PlayAlong(turn=t) | TryThis(turn=t):
                                 return ended_active == owner and ended_turn > t
        case FullForce():        return False
```

## Последствия: `settle`

После каждого действия — в этом порядке:

1. **Гибель.** Кто погиб этим действием — `Died`; снимаются
   `PlayAlong`, нацеленные на него.
2. **Конец раунда.** Живых ≤ 1 — см. [конец раунда](#конец-раунда-и-игры).
   Дальше не проверяется.
3. **Конец хода.** Если действие закончило ход или активный погиб:
   истекают эффекты (`expired`, `EffectRemoved`), `turn += 1`, `active` —
   следующий живой по кругу (`TurnPassed`).
4. **Конец ряда.** Все каморы использованы — `SpreadEnded`, `start_spread`.
   Если ход не кончился, он продолжается в новом ряду.
