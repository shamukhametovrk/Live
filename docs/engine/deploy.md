# Деплой

Движок — один процесс с одним столом в памяти. Поэтому сервер всегда один:
вторая машина завела бы второй, несвязанный стол.

## Образ

`engine/Dockerfile` собирает образ: Python ставит uv, зависимости — по
`uv.lock` без dev-группы. Наружу — порт 8080: и WebSocket `/ws`, и
веб-клиент на `/`. Проверить локально:

```bash
cd engine
docker build -t live-engine .
docker run --rm -p 8080:8080 live-engine
```

Открыть <http://localhost:8080>.

## Fly.io

Настройки — в `engine/fly.toml`. Первый раз:

```bash
cd engine
fly launch --no-deploy --copy-config --name <имя-приложения>
fly deploy --ha=false
```

Дальше — просто `fly deploy`. `--ha=false` держит одну машину.

Игра будет на `https://<имя-приложения>.fly.dev`. За HTTPS клиент сам
подключается по `wss://`.

Когда за столом никого, Fly останавливает машину, а первый заход будит
её. Стол при этом пропадает — для прототипа это нормально.

## Render

Подойдёт и Render: новый Web Service из репозитория, среда Docker, корень
`engine`, порт 8080. Бесплатный план засыпает после 15 минут без
запросов — стол так же пропадает.
