# Деплой

Движок — один процесс с одним столом в памяти. Поэтому сервер всегда один:
второй экземпляр завёл бы второй, несвязанный стол.

## Образ

`engine/Dockerfile` собирает образ: Python ставит uv, зависимости — по
`uv.lock` без dev-группы. Наружу — один порт из переменной `PORT` (без неё
— 8080): и WebSocket `/ws`, и веб-клиент на `/`. Проверить локально:

```bash
cd engine
docker build -t live-engine .
docker run --rm -p 8080:8080 live-engine
```

Открыть <http://localhost:8080>.

## Render

Один раз в панели Render: **New → Web Service** из репозитория.

| Поле | Значение |
| --- | --- |
| Language | Docker |
| Branch | `main` |
| Root Directory | `engine` |
| Instance Type | Free |

`PORT` Render задаёт сам. Дальше каждый пуш в `main` выкатывается заново.

Игра будет на `https://<имя-сервиса>.onrender.com`. За HTTPS клиент сам
подключается по `wss://`.

Бесплатный сервис засыпает после 15 минут без запросов, первый заход
будит его примерно за минуту. Стол при этом пропадает, как и при каждом
деплое, — для прототипа это нормально.
