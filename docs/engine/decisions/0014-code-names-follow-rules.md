# 0014. Имена в коде — как в правилах

Заменяет [0008](0008-match-not-party.md).

**Контекст.** Правила перешли на уровни Игра → Раунд → Ряд → Ход, а код
остался на старых: `Match` — нынешний раунд, `Round` — нынешний ряд.
Одно слово «раунд» значило разное в правилах и в коде.

**Решение.** Уровни в коде называются по правилам: `Game`, `Round`,
`Spread`, `Turn`. Переименование — вместе с переходом на
[неизменяемое состояние](0012-immutable-state-pure-rules.md).

**Последствия.** «Старые термины» из документации движка уходят вместе
с переписыванием доменного слоя.
