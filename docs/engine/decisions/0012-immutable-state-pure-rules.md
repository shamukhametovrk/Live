# 0012. Неизменяемое состояние, правила — чистые функции

Заменяет [0006](0006-mutable-entities-in-repository.md).

**Контекст.** Изменяемые сущности дублировались неизменяемыми снимками
`*State`: каждое поле жило в двух местах. Инварианты охранялись и в
сущностях, и в правилах, а большую часть кода занимали проверки на
баги самого движка.

**Решение.** Модель домена — одно неизменяемое состояние (frozen
dataclass) с вложенными состояниями уровней. Правило — чистая функция
`apply(state, actor, command, rng) -> Outcome(state, events)`.
Недопустимая команда — исключение `IllegalAction(code)`; баг движка —
`InvariantViolation`. Изменяемых сущностей нет.

**Последствия.** Одна модель вместо двух, проверка команды — в одном
месте. История, повтор и откат хода — это просто последовательность
состояний. Инварианты состояния проверяются тестами, а не кодом
сущностей. Порт репозитория хранит текущее состояние, а не агрегат.
Каждый ход копирует состояние — для игры на шестерых это ничтожно.
