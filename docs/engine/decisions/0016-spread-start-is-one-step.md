# 0016. Начало ряда — один шаг для движка

**Контекст.** В правилах начало ряда идёт так: выдача → объявление камор →
фишки. Движку это давало два ожидания всех игроков подряд и два
состояния ряда.

**Решение.** Выбор руки ни на что в раскладке фишек не влияет, поэтому
движок отдаёт выдачу и число камор сразу, а игрок присылает одно решение
`prepare(hand, chips)`. Порядок из правил соблюдает клиент на экране.
Формулировка — в [правилах домена](../architecture/domain/rules.md#начало-ряда).

**Последствия.** У ряда два состояния: `Preparing` и `Shooting`. Правила
игры не меняются. Клиент технически узнаёт число камор до выбора руки.
