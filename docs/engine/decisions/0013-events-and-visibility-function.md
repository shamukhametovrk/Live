# 0013. Правило возвращает события, сообщения выводит видимость

Заменяет [0011](0011-rules-return-events-and-messages.md).

**Контекст.** Если каждое правило само пишет сообщения, таблица
[видимости](../../rules/visibility.md) оказывается размазанной по всем
правилам, а забытое сообщение тихо рассинхронизирует клиента. Особую
видимость имеют лишь восемь предметов и два шага начала ряда, и все они
сводятся к двум приёмам: событие с адресатом или скрытое поле.

**Решение.** Правило возвращает только **события** — полную правду.
Модуль видимости превращает их в **сообщения**:
`project(event, player) -> Message | None`, и он же отдаёт снимок:
`view(state, player)`. Событие, которое видит один игрок, несёт
адресата; скрытое поле события вырезается для тех, кому его видеть
нельзя. Результаты одновременного выбора (выдача, фишки) — одно событие
в конце шага.

**Последствия.** Видимость в коде живёт в одном месте, как и в правилах.
Новый предмет с особой видимостью добавляет ветку в модуль видимости.
Тест «снимок + сообщения = снимок» остаётся обязательным.
