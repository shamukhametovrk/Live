# 0015. Эффекты — данные, поведение — по моментам игры

**Контекст.** Рассматривались крючки: модуль предмета или эффекта
объявляет `on_hit`, `on_turn_end`, а выстрел и передача хода их
вызывают. Тогда взаимодействие эффектов (например, «Щит» против «Со всей
дури») зависело от порядка вызова и не было видно ни в одном модуле.

**Решение.** Эффект — класс-данные без методов, по классу на вид
(`Double`, `FullForce`, `Shield`, `PlayAlong`, `TryThis`). Поведение
сгруппировано по моменту игры: урон, «Дубль» и принуждения — в выстреле,
сроки — в одной функции `expired`. Разбор по виду — `match` с
`assert_never`. Формулировка — в [правилах домена](../architecture/domain/rules.md#эффекты).

**Последствия.** Взаимодействие эффектов записано явно и в одном месте.
Новый эффект — правка выстрела или `expired`, а не новый файл;
тайпчекер не даст забыть случай. «Одинаковые эффекты» — эффекты одного
класса.
