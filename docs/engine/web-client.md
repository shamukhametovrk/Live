# Веб-клиент (прототип)

Прототип клиента, чтобы проверить, интересно ли играть. Живёт в движке
(`engine/web/`), и движок сам отдаёт его на `/`. Страница подключается к
тому же адресу, с которого открыта: друзьям достаточно ссылки на хоста.
Говорит с движком только JSON по WebSocket, как будет говорить настоящий
клиент.

Интерфейс пока простой: его внешний вид будет обсуждаться отдельно.

## Файлы

| Файл | Что в нём |
| --- | --- |
| `index.html` | разметка экранов |
| `style.css` | оформление: палитра «Бутылочное стекло», как у сайта |
| `icons/` | значки предметов; откуда каждый — в `icons/README.md` |
| `logo.svg`, `favicon.svg` | вывеска и иконка вкладки — копии из `docs/` |
| `text.js` | русские названия предметов, эффектов, тексты отказов и сообщений |
| `net.js` | соединение, JSON, переподключение по токену |
| `screens.js` | отрисовка экранов по снимку и ввод игрока |
| `play.js` | проигрывание сообщений: очередь, анимации, подписи |
| `main.js` | запуск: связывает соединение с проигрыванием и экранами |

Скрипты обычные, не модули: так страница работает и открытая файлом.

## Как клиент думает

- Сообщение движка — подпись у игрока, к которому оно относится;
  служебные (кто решил, чей ход) не показываются: их видно по столу.
- После сообщения клиент просит свежий снимок и перерисовывает экран по
  нему. Сообщения сперва проигрываются по очереди, каждое — анимацией на
  уже нарисованном столе; снимок рисуется, когда очередь опустела. Так
  выстрел успевает вскрыть камору, даже если ряд на нём закончился.
  Сообщение о новом состоянии (начало раунда, ряда, заряжание) ждёт свой
  снимок и рисует его до анимации. Пока идёт анимация, ввод ждёт. Картину мира он не собирает (см.
  [сообщения и снимок](architecture/domain/commands.md#сообщения-и-снимок)).
- Токен хранится в браузере: после перезагрузки страницы или обрыва
  клиент сам возвращается за стол.
- Отказ движка — красная подпись понятными словами.

## Дизайн

Прототип для плейтеста: игра должна ощущаться, но без библиотек — чистые
HTML, CSS и SVG. Стиль — палитра «Бутылочное стекло», как у сайта:
рисованный стол под лампой, неоновые метки поверх. Текста как можно
меньше: значки вместо слов и чисел. Звука пока нет.

### Стол

Круглый стол, вид сверху.

- **Игроки** сидят по кругу в порядке хода. Вы — всегда внизу: стол
  повёрнут к вам.
- **Каморный ряд** — линией через центр стола. Фишки лежат у камор.
- **Рука** каждого игрока лежит на столе перед ним: предметы —
  значками, цвет значка — класс предмета: обычный — сталь, редкий —
  cyan, потолочный — янтарь. Ваша рука крупнее, под столом.
- **Жизни** — ряд огоньков, **фишки** — стопка фишек, штуками, а не
  числом.
- **Эффекты** горят значками у игрока.
- **Число патронов** вспыхивает, когда ряд заряжен, и гаснет: дальше его
  держат в голове. Это только интерфейс — снимок движка число хранит.
- **Ленты нет.** Сообщения движка — короткие всплывающие подписи у
  игрока или каморы, к которым они относятся.

### Ввод

- **Выстрел**: клик по каморе берёт её, клик по игроку (или по себе) —
  выстрел.
- **Предмет**: клик по предмету в руке, дальше — клики по тому, что он
  просит (камора, игрок). Повторный клик по предмету или Esc — отмена.
- **Начало ряда** — окно поверх стола:
    - две полки: рука (8 слотов) и сброс; клик перекладывает предмет
      между ними. Сначала в руке всё, что влезает: прежняя рука, потом
      выдача; лишнее — в сбросе;
    - выдача вылетает на полку по одному предмету;
    - при наведении на предмет — его название и что он делает одной
      строкой;
    - мини-ряд: клик по каморе кладёт фишку, клик по фишке или правый
      клик — забирает;
    - «Готово» открывается, когда все фишки разложены.

### Анимации

Анимаций столько, чтобы прочувствовать игру:

| Момент | Что видно |
| --- | --- |
| Заряжание ряда | каморы выкладываются на стол, число патронов вспыхивает и гаснет |
| Выстрел | камора вскрывается; попадание — вспышка, тряска стола, гаснет огонёк жизни; холостой — щелчок-подпись |
| Предмет | значок летит от применившего к цели: каморе, ряду или игроку; эффект — подписью у игрока |
| Передача хода | огонёк на ободе стола бежит к следующему игроку |
| Щит | вспышка ультрафиолетом у игрока вместо крови |
| Гибель | игрок вспыхивает красным и гаснет |
| Победа в раунде | подпись у победителя |

### Значки

Значки предметов — [game-icons.net](https://game-icons.net) (CC BY 3.0):
строка авторства — внизу страницы клиента. Эффект рисуется значком
предмета, который его оставил. Подпись о применённом предмете — его
значок и короткий итог. Движок отдаёт страницу с `Cache-Control:
no-cache`: после обновления браузер не смешает старые скрипты с новыми.

### Остальные экраны

| Экран | Что на нём |
| --- | --- |
| Лобби | отдельный экран: кто за столом, «Сесть»; у хоста — число раундов и «Начать» |
| Пауза | поверх стола: кто потерял связь |
| Конец игры | победители, счёт по раундам |

## Боты

`tools/net_bot.py` — сетевой бот: обычный клиент без экрана, говорит
только JSON. Садится за стол и играет случайно. Нужен, чтобы играть одному
и проверять протокол. (Бот `tools/bot.py` — другой: он играет напрямую с
доменом в сквозных тестах и летописи.)

## Запуск

```bash
cd engine
uv run uvicorn engine.adapters.websocket:create_app --factory
```

Открыть <http://localhost:8000>, «Сесть за стол». Добавить двух ботов:

```bash
cd engine
uv run python -m tools.net_bot --count 2
```

Друзьям по сети: хост добавляет к запуску движка `--host 0.0.0.0`, друзья
открывают `http://адрес-хоста:8000`.

## Проверка

- Движок отдаёт страницу — тест адаптера.
- Протокол — сквозной прогон: движок поднимается на свободном порту,
  сетевые боты проходят партию до конца через настоящий WebSocket.
- Экран — глазами в браузере.
