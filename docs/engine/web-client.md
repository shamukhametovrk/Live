# Веб-клиент (прототип)

Прототип клиента, чтобы проверить, интересно ли играть. Живёт в движке
(`engine/web/`), и движок сам отдаёт его на `/`. Страница подключается к
тому же адресу, с которого открыта: друзьям достаточно ссылки на хоста.
Говорит с движком только JSON по WebSocket, как будет говорить настоящий
клиент.

Интерфейс пока простой: его внешний вид будет обсуждаться отдельно.

## Файлы

| Файл | Что в нём |
| --- | --- |
| `index.html` | разметка экранов |
| `style.css` | оформление: палитра «Бутылочное стекло», как у сайта |
| `logo.svg`, `favicon.svg` | вывеска и иконка вкладки — копии из `docs/` |
| `text.js` | русские названия предметов, эффектов, тексты отказов и сообщений |
| `net.js` | соединение, JSON, переподключение по токену |
| `screens.js` | отрисовка экранов по снимку и ввод игрока |

Скрипты обычные, не модули: так страница работает и открытая файлом.

## Как клиент думает

- Каждое сообщение движка — строка в ленте.
- После сообщения клиент просит свежий снимок и перерисовывает экран по
  нему. Картину мира он не собирает (см.
  [сообщения и снимок](architecture/domain/commands.md#сообщения-и-снимок)).
- Токен хранится в браузере: после перезагрузки страницы или обрыва
  клиент сам возвращается за стол.
- Отказ движка — строка в ленте понятными словами.

## Экраны

| Экран | Что на нём |
| --- | --- |
| Лобби | кто за столом, «Сесть»; у хоста — число раундов и «Начать» |
| Начало ряда | число камор, выдача и прежняя рука с отметками «оставить», фишки по каморам, «Готово», кто уже решил |
| Стрельба | игроки сверху, ряд по центру, лента, рука и фишки внизу; выбор каморы и цели кликом, предмет — кликом по нему |
| Пауза | поверх экрана: кто потерял связь |
| Конец игры | победители, счёт по раундам, история событий |

## Боты

`tools/net_bot.py` — сетевой бот: обычный клиент без экрана, говорит
только JSON. Садится за стол и играет случайно. Нужен, чтобы играть одному
и проверять протокол. (Бот `tools/bot.py` — другой: он играет напрямую с
доменом в сквозных тестах и летописи.)

## Запуск

```bash
cd engine
uv run uvicorn engine.adapters.websocket:create_app --factory
```

Открыть <http://localhost:8000>, «Сесть за стол». Добавить двух ботов:

```bash
cd engine
uv run python -m tools.net_bot --count 2
```

Друзьям по сети: хост добавляет к запуску движка `--host 0.0.0.0`, друзья
открывают `http://адрес-хоста:8000`.

## Проверка

- Движок отдаёт страницу — тест адаптера.
- Протокол — сквозной прогон: движок поднимается на свободном порту,
  сетевые боты проходят партию до конца через настоящий WebSocket.
- Экран — глазами в браузере.
