# Клиент

Клиент — приложение, за которым сидит игрок: оно показывает стол, принимает
действия и отправляет их движку.

Первым будет простой **веб-клиент** — проверить, интересно ли играть.
Настоящий клиент (скорее всего на Godot) — потом.

| Раздел | О чём |
| --- | --- |
| [Веб-клиент](web.md) | Страница в браузере: экраны, как думает, как запустить |

Исходники клиентов лежат в папке `client/` репозитория. Говорят они с
движком только JSON по WebSocket (см.
[адаптеры движка](../engine/architecture/adapters/README.md)) и код
движка не импортируют.
