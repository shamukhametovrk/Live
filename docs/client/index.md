# Клиент

Клиент — приложение, за которым сидит игрок: оно показывает стол, принимает
действия и отправляет их движку.

Настоящий клиент (скорее всего на Godot) будет жить в папке `client/`
репозитория и говорить с движком только JSON по WebSocket (см.
[адаптеры движка](../engine/architecture/adapters/README.md)).

Пока его нет. Играть можно в прототипе —
[веб-клиенте](../engine/web-client.md), который отдаёт сам движок.
