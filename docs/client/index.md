# Клиент

Клиент — приложение, за которым сидит игрок: оно показывает стол, принимает
действия и отправляет их движку.

!!! note "Пока — пусто"

    Клиента ещё нет. Сначала доводятся [правила](../rules/index.md) и пишется
    [движок](../engine/index.md); первым будет простой консольный клиент —
    проверить, интересно ли играть, — и только потом настоящий.

Исходники клиентов будут лежать в папке `client/` репозитория, а их
документация — здесь.
