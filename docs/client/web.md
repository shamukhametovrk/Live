# Веб-клиент

Статичная страница: HTML, CSS и JavaScript без сборки и зависимостей.
Её можно открыть файлом или отдать любым статичным сервером. По
умолчанию она подключается к движку на `localhost:8000`; другой адрес
вводят на первом экране или передают в ссылке:
`index.html?server=192.168.1.5:8000`.

Интерфейс пока простой: его внешний вид будет обсуждаться отдельно.

## Файлы

| Файл | Что в нём |
| --- | --- |
| `index.html` | разметка экранов |
| `style.css` | оформление: ретро-терминал |
| `text.js` | русские названия предметов, эффектов, тексты отказов и сообщений |
| `net.js` | соединение, JSON, переподключение по токену |
| `screens.js` | отрисовка экранов по снимку и ввод игрока |

Скрипты обычные, не модули: так страница работает и открытая файлом.

## Как клиент думает

- Каждое сообщение движка — строка в ленте.
- После сообщения клиент просит свежий снимок и перерисовывает экран по
  нему. Картину мира он не собирает (см.
  [сообщения и снимок](../engine/architecture/domain/commands.md#сообщения-и-снимок)).
- Токен хранится в браузере: после перезагрузки страницы или обрыва
  клиент сам возвращается за стол.
- Отказ движка — строка в ленте понятными словами.

## Экраны

| Экран | Что на нём |
| --- | --- |
| Подключение | адрес движка, «Подключиться» |
| Лобби | кто за столом, «Сесть»; у хоста — число раундов и «Начать» |
| Начало ряда | число камор, выдача и прежняя рука с отметками «оставить», фишки по каморам, «Готово», кто уже решил |
| Стрельба | игроки сверху, ряд по центру, лента, рука и фишки внизу; выбор каморы и цели кликом, предмет — кликом по нему |
| Пауза | поверх экрана: кто потерял связь |
| Конец игры | победители, счёт по раундам, история событий |

## Боты

`client/bot/` — бот на Python, обычный клиент без экрана: подключается по
WebSocket, садится за стол и играет случайно. Нужен, чтобы играть одному и
проверять протокол.

## Запуск

```bash
cd engine
uv run uvicorn engine.adapters.websocket:create_app --factory
```

Открыть `client/web/index.html` в браузере. Добавить двух ботов:

```bash
cd client/bot
uv run bot.py --count 2
```

Друзьям по сети: хост запускает движок с `--host 0.0.0.0`, друзья
открывают страницу со своим адресом хоста.

## Проверка

Протокол — сквозной прогон: движок поднимается на свободном порту, боты
проходят партию до конца через настоящий WebSocket. Экран — глазами в
браузере.
