# Раунд

**Раунд**{ #t-раунд .term } — часть [игры](game.md), которая длится, пока
в живых не останется один игрок.

## Начало раунда

1. Каждый игрок получает одинаковое число
   [жизней](../elements/player.md#t-жизнь). Сколько — сказано в
   [параметрах](../parameters.md).
2. Порядок игроков в [круге](../elements/player.md#t-круг) перемешивается
   случайно.
3. Определяется **первый ходящий**{ #t-первый-ходящий .term } — тот, кто
   сделает первый ход раунда. Им становится тот, кто начинал раунды реже
   всех, а если таких несколько — случайный из них. Так каждый начинает
   раунды одинаково часто.

После этого начинается первый ряд.

## Ряды

Ряды идут один за другим, пока в живых больше одного игрока.

## Конец раунда

Раунд заканчивается, как только в живых остаётся один игрок, — даже
посреди ряда. Тогда ряд обрывается: конца ряда не бывает.

Оставшийся в живых выигрывает раунд.

Жизни, рука, фишки и [эффекты](../items/index.md#t-эффект) сгорают. Следующий раунд все начинают заново,
погибшие тоже.
