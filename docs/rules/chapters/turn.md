# Ход

**Ход**{ #t-ход .term } — часть [ряда](spread.md), в которую действует
один игрок. Тот, чей сейчас ход, —
**активный игрок**{ #t-активный-игрок .term }.

## Предметы

До выстрела активный игрок может применять [предметы](../items/index.md#t-предмет)
из [руки](../elements/hand.md#t-рука). Не в свой ход предметы не
применяются.

## Выстрел

**Выстрел**{ #t-выстрел .term } — действие, которым обычно заканчивается ход. Активный игрок
выбирает:

- **камору** — любую неиспользованную;
- **цель**{ #t-цель .term } — любого [живого](../elements/player.md#t-живой)
  игрока, в том числе себя.

Выбранная камора становится
[использованной](../elements/chamber-row.md#t-использованная-камора).

- Был патрон — это **попадание**{ #t-попадание .term }: цель теряет одну
  [жизнь](../elements/player.md#t-жизнь).
- Было пусто — это **холостой**{ #t-холостой .term } выстрел: ничего не
  происходит.

## Фишки

Игрок получает одну [фишку](../elements/chips.md#t-фишка), если:

- выстрелил в себя,
- выстрел оказался холостым,
- и в ряду при этом оставался хотя бы один патрон.

## Конец хода

Ход заканчивается:

- выстрелом;
- когда его заканчивает [предмет](../items/index.md#t-предмет);
- сразу, как только активный игрок
  [погиб](../elements/player.md#t-погибший).

После этого ход переходит к следующему
живому игроку по [кругу](../elements/player.md#t-круг).
