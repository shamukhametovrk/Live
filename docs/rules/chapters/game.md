# Игра

**Игра**{ #t-игра .term } — серия [раундов](round.md) с одним и тем же
составом [игроков](../elements/player.md#t-игрок).

## Начало игры

Игроки договариваются, сколько раундов сыграют, в пределах из
[параметров](../parameters.md). После этого начинается первый раунд.

## Раунды

Раунды идут один за другим. Когда раунд закончился, а раунды ещё
остались, начинается следующий.

## Конец игры

Игра заканчивается, когда сыгран последний раунд.

Побеждает тот, кто выиграл больше всех раундов. Если таких несколько,
они делят победу.
