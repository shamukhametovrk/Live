# Пора делиться

<span class="cls cls--rare">редкий</span>

Забирает у выбранного соперника на выбор применившего: либо случайный предмет из его руки, либо одну фишку из тех, что он заработал в этом ряду.

Забранный предмет попадает в руку применившего — место есть всегда, потому что «Пора делиться» из руки уходит. Применить его можно сразу, как любой другой предмет.

Если случайно выпала «Пора делиться», предмет тратится впустую: у соперника ничего не забирают.
