# Мне страшно

<span class="cls cls--common">обычный</span>

Убирает из ряда один патрон. Его снимают с одной из неиспользованных камор с патроном — выбор идёт обратно весам: тяжёлую камору разряжают реже.

Обратный вес каморы — наибольший [вес](../elements/chips.md#t-вес) в ряду плюс один минус вес этой каморы. Шанс каморы пропорционален её обратному весу. Например, если заряжены каморы с весами $1,\ 2,\ 4$, а наибольший вес в ряду $4$, обратные веса — $4,\ 3,\ 1$, а шансы — $50\%,\ 37{,}5\%,\ 12{,}5\%$.

Если патронов в ряду нет, предмет тратится впустую.
