# Попробуй вот эту

<span class="cls cls--rare">редкий</span>

Применивший называет любого живого игрока, в том числе себя, и неиспользованную камору. В свой следующий ход этот игрок обязан выбрать для выстрела именно её. Если камору используют раньше, ограничение снимается. Если игрок закончил ход без выстрела, ограничение тоже снимается.
