# Настроечный щит

<span class="cls cls--rare">редкий</span>

Оставляет [эффект](index.md#t-эффект): следующее попадание в применившего не отнимает жизнь. Эффект держится до начала его следующего хода.

Попадание гасится целиком, даже усиленное [«Со всей дури»](full-force.md): тогда сгорают оба эффекта.
