# Параметры

| Параметр | Значение |
| --- | --- |
| Игроки за столом | от 2 до 6 |
| Раунды в игре | от 1 до 7, по договорённости игроков |
| Жизни в начале раунда | случайно от 2 до 5, одинаково для всех |
| Каморы в ряду | случайно от 4 до 12 |
| Патроны в ряду | случайно от 1 до числа камор без одной |
| Лимит руки | 8 предметов |
| Набор выдачи | 2 или 3 предмета; класс каждого случайный: обычный — 60%, редкий — 30%, потолочный — 10% |
