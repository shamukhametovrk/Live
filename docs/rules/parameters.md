# Параметры

Параметры с пометкой «настройка» [хост](chapters/game.md#t-хост) задаёт
до начала игры внутри указанных пределов. По умолчанию пределы
используются целиком.

| Параметр | Значение | Настройка |
| --- | --- | --- |
| Игроки за столом | от 2 до 6 | |
| Раунды в игре | от 1 до 7 | число |
| Жизни в начале раунда | случайно от 2 до 5, одинаково для всех | пределы «от–до» |
| Каморы в ряду | случайно от 4 до 12 | пределы «от–до» |
| Патроны в ряду | случайно от 1 до 11, но не больше числа камор без одной | пределы «от–до»; нижний предел патронов меньше нижнего предела камор |
| Предметы в игре | все из [каталога](items/index.md#каталог) | какие исключить |
| Лимит руки | 8 предметов | |
| Набор выдачи | случайно от 0 до 4 предметов, с равным шансом; класс каждого случайный: обычный — 60%, редкий — 30%, потолочный — 10%. Класс без предметов в игре не выпадает: его шанс делится между остальными пропорционально | |
| Ожидание при потере связи | 60 секунд | |
