# Рука

**Рука**{ #t-рука .term } — [предметы](../items/index.md#t-предмет), которые держит
игрок.

## Лимит руки

**Лимит руки**{ #t-лимит-руки .term } — сколько предметов можно держать в
руке. Сам лимит указан в [параметрах](../parameters.md).

## Кто видит

Руку каждого игрока видят все. Во время
[выдачи](../chapters/spread.md#t-выдача) — что выпало каждому и что он
оставил — другие узнают, только когда выбор сделали все.
