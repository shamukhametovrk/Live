# Фишки

**Фишка**{ #t-фишка .term } — игровая единица, которую игрок зарабатывает в
[ходе](../chapters/turn.md#фишки) и кладёт на камору в
[начале ряда](../chapters/spread.md#начало-ряда). Фишки на каморе влияют на
[зарядку](../chapters/spread.md#t-зарядка).

## Где бывает фишка

- **У игрока** — заработана, но ещё не положена.
- **На каморе** — положена.

## Вес каморы

**Вес**{ #t-вес .term } каморы — единица плюс все фишки, которые на ней
лежат, не важно чьи. Камора без фишек весит один.

## Кто видит

- Сколько фишек заработал каждый игрок, видят все.
- Свои фишки на каморах игрок видит сам. Чужие не видит никогда.
- Вес каморы не видит никто. Узнать его можно только
  [предметом](../items/index.md#знание).
